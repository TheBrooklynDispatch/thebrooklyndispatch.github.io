# The Brooklyn Dispatch — v1

A static editorial website designed for GitHub Pages.

## Files
- `index.html` — homepage
- `film/`, `books/`, `new-york/` — section pages
- `about/` — about page
- `articles/physical-culture.html` — sample article template
- `assets/styles.css` — complete visual system
- `assets/script.js` — mobile navigation + reading progress
- `404.html` — custom 404
- `feed.xml` — starter RSS feed
- `sitemap.xml` — starter sitemap
- `robots.txt`

## Deploy
Upload the contents of this folder to the root of your GitHub Pages repository.

## Design direction
- Warm monochrome paper
- Near-black text
- Acid-lime accent
- Editorial serif headlines + restrained sans-serif UI
- No rounded cards, shadows, or startup-style UI
